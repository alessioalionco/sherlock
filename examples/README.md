# Read a Sherlock dossier

**This example is entirely synthetic.** Its organization, products, source text, dates, and analytical events are invented. It is a small editorial demonstration, not a research execution, benchmark, or complete N/7N delivery. It demonstrates format and navigation, not research quality or successful compliance with the skill.

Start at the [sample dossier](sample-dossier/README.md). The fictional team needs to know whether a help desk export can support a migration with attachments intact. Its illustrative brief distinguishes that primary objective from customer identity mapping as a secondary one.

No execution receipt, transcript, hash manifest, PDF, or check result is supplied. None was generated for a research run. The miniature intentionally omits the full report and most of a production dossier. In real use, missing required deliverables must be reported as partial; this teaching sample is not an exception that changes that contract.
